## 2. C++ Concepts Used

### `std::vector<float>`

Used to store a vector of floating-point numbers.

Example:

    std::vector<float> a{1.0F, 2.0F, 3.0F};

### Pass by Value

    std::vector<float> a

Creates a copy of the vector.

Changes inside the function do not affect the original vector.

### Pass by Reference

    std::vector<float>& a

Does not copy the vector.

The function works with the original vector and can modify it.

### Const Reference

    const std::vector<float>& a

Does not copy the vector, but prevents the function from modifying it.

This is useful for Skadi because vectors may eventually contain hundreds or thousands of values, so unnecessary copies could be expensive.

### Header and Source Files

`vector_math.h`

Declares the functions that are available.

`vector_math.cpp`

Contains the actual implementations.

### `<cmath>`

Provides mathematical functions such as:

    std::sqrt()

### `^` in C++

`^` does NOT mean "raise to a power".

It is the bitwise XOR operator.

To square something we currently use:

    x * x

## 3. Vector Search Concepts

### Embeddings

An embedding is a vector of numbers generated by a model.

Conceptually:

    "dog" -> [0.21, -0.73, 0.14, ...]
    "cat" -> [0.24, -0.69, 0.18, ...]
    "car" -> [-0.51, 0.12, 0.91, ...]

Similar things should generally produce vectors that are close together in the embedding space.

### Dimensions

The embedding model determines the number of dimensions.

Examples might be:

    384 dimensions
    768 dimensions
    1536 dimensions

Skadi does not initially create embeddings.

Its job will be to store and search vectors produced elsewhere.

### Matching Dimensions

Vectors must have the same number of dimensions to calculate standard distances between them.

For example:

    [1, 2, 3]
    [4, 5, 6]

can be compared.

But:

    [1, 2, 3]
    [4, 5]

cannot be directly compared using Euclidean distance.

Eventually Skadi must validate this.

### Euclidean Distance

Euclidean distance measures how far apart two vectors are.

For:

    a = [1, 2, 3]
    b = [4, 5, 6]

the distance is:

    sqrt(
        (1 - 4)^2 +
        (2 - 5)^2 +
        (3 - 6)^2
    )

    = sqrt(27)
    = 5.19615

Smaller distance means the vectors are closer together.

## Current Skadi Capabilities
